# Spec Delta

## MODIFIED Requirements

### Requirement: Очистка состояния игрока

Плагин SHALL удалять связанные задачи и сбрасывать countdown/AFK-состояние при каждом disconnect, включая отмену подключения до входа игрока на сервер.

#### Scenario: Слот игрока переиспользован

- **WHEN** один клиент отключился и другой занял тот же id
- **THEN** новый клиент не наследует задачи, AFK-команду или выключенный countdown-звук предыдущего

#### Scenario: Клиент отменил подключение

- **WHEN** после `client_connect` соединение прерывается до полноценного входа на сервер
- **THEN** disconnect cleanup удаляет задачи и сбрасывает состояние выделенного player id

# Spec Delta

## ADDED Requirements

### Requirement: Каноническое название проекта

Каноническое отображаемое название проекта SHALL быть `Hide And Seek: Ultimate`. Управляемые текущим проектом metadata плагина, основная документация и релизные материалы MUST использовать это точное написание, а стабильные технические идентификаторы HNS SHALL сохраняться без переименования.

#### Scenario: Администратор просматривает список плагинов

- **WHEN** собранный плагин загружен на сервер и администратор выполняет `amxx plugins`
- **THEN** AMXX отображает имя `Hide And Seek: Ultimate`

#### Scenario: Пользователь открывает документацию или новый релиз

- **WHEN** пользователь открывает основной README, справку release tool или GitHub Release, созданный из актуальной версии проекта
- **THEN** отображаемое название записано как `Hide And Seek: Ultimate`

#### Scenario: Сервер обновляется после переименования

- **WHEN** владелец сервера устанавливает версию с новым отображаемым названием поверх существующей HNS-установки
- **THEN** имена `hns.sma`, `hns.amxx`, `hns.cfg`, `hns.txt`, Cvar с префиксом `hns_`, пути ресурсов и имена релизных assets остаются совместимыми

### Requirement: Канонический GitHub-репозиторий

Основной GitHub-репозиторий проекта SHALL быть доступен по адресу `https://github.com/iwonz/amxx-hns-ultimate`. Управляемая проектом документация MUST ссылаться на новый repository path и не зависеть от перенаправления со старого адреса.

#### Scenario: Пользователь открывает репозиторий

- **WHEN** пользователь переходит по canonical repository URL
- **THEN** GitHub открывает репозиторий `iwonz/amxx-hns-ultimate`

#### Scenario: Пользователь получает релиз

- **WHEN** пользователь следует по ссылке GitHub Releases из основной документации
- **THEN** ссылка ведёт на `https://github.com/iwonz/amxx-hns-ultimate/releases`

#### Scenario: Разработчик продолжает работу после переименования

- **WHEN** репозиторий переименован и текущий checkout подготовлен к следующему fetch или push
- **THEN** его `origin` указывает на `https://github.com/iwonz/amxx-hns-ultimate.git`

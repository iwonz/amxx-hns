# Proposal

## Why

Версия плагина сейчас задана вручную как `1.0`, не соответствует полной форме SemVer и не связана ни с Git-тегами, ни с GitHub Releases. Из-за этого опубликованный бинарник невозможно однозначно сопоставить исходному коду, а релиз легко собрать или назвать версией, отличающейся от зарегистрированной внутри `hns.amxx`.

## What Changes

- Ввести единый источник версии плагина в формате SemVer 2.0.0 и нормализовать текущую версию до `1.0.0` без изменения игрового поведения.
- Использовать эту версию в метаданных `register_plugin`, документации, проверках и именах релизных артефактов.
- Ввести релизный Git-тег `v<SemVer>` и запрещать публикацию, если тег невалиден или не совпадает с версией исходника.
- Добавить GitHub Actions workflow, который по SemVer-тегу проверяет проект, компилирует `hns.amxx` закреплённым официальным AMX Mod X 1.10, собирает готовый к установке архив и создаёт GitHub Release с контрольными суммами.
- Удалить legacy include `dhudmessage`, отсутствующий в официальном пакете AMX Mod X 1.10.0.5487: используемые DHUD natives уже объявлены стандартным `amxmodx.inc`, поэтому runtime-поведение не меняется.
- Зафиксировать правила повышения MAJOR/MINOR/PATCH, выпуск prerelease и последовательность публикации релиза в release-спецификации и design-документации, не перегружая операторский README внутренним процессом сопровождения.
- Добавить регрессионные проверки формата версии, единственного источника истины, структуры workflow и релизного архива.
- Не добавлять и не изменять Cvar, чат-команды, игровые assets или ключи локализации.
- Вне scope: автоматический выбор следующей версии по истории коммитов, публикация при каждом push в `master`, подпись артефактов, контейнерный образ и изменение игровой логики.

Изменение обратно совместимо для серверов: конфигурация, команды, ресурсы и правила режима остаются прежними. Меняется только строка версии с `1.0` на SemVer-эквивалент `1.0.0` и появляется официальный канал бинарных поставок.

## Capabilities

### New Capabilities

- `release-versioning`: единая SemVer-версия плагина, соответствие Git-тега и GitHub Release, воспроизводимая проверка, сборка и упаковка релизных артефактов.

### Modified Capabilities

- `core-boundaries`: уточнить официальный набор include AMX Mod X 1.10 и отсутствие зависимости от устаревшего `dhudmessage.inc`.

## Impact

- Pawn: `src/scripting/hns.sma`, новый внутренний include с версией и удаление избыточного `#include <dhudmessage>`.
- Автоматизация: новый локально запускаемый release helper и `.github/workflows/release.yml`.
- Поставка: GitHub Releases с `hns-v<version>.zip`, отдельным `hns.amxx` и файлом контрольных сумм.
- Документация и проверки: `README.md`, Python regression tests и новая спецификация `release-versioning`.
- Внешние зависимости CI: официальный AMX Mod X `1.10.0.5487`, стандартный Python 3, GitHub CLI и `GITHUB_TOKEN` с минимальным `contents: write` только для release job.

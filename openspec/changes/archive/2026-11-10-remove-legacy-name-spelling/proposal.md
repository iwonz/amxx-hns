# Proposal

## Why

После переименования каноническое имя проекта уже используется в активном коде и документации, но точное устаревшее сокращённое написание всё ещё встречается в regression-тесте и архивированных OpenSpec-артефактах. Пользователь требует единообразия во всех файлах текущего checkout, включая архив.

## What Changes

- Убрать все пять оставшихся точных вхождений устаревшего написания из `tests/test_project_docs.py` и `openspec/changes/archive/`.
- Сохранить смысл отрицательной regression-проверки, формируя legacy-строку из частей без хранения полного устаревшего написания в исходнике теста.
- Переформулировать исторические proposal/design/tasks так, чтобы они использовали только `Hide And Seek: Ultimate` либо описательное выражение без legacy-строки.
- Добавить проверку нулевого числа точных вхождений во всём checkout, исключая только внутренний каталог `.git`.
- Не переписывать commit history, GitHub Releases или иные данные вне файлов текущего checkout.
- Изменение не затрагивает Cvar, чат-команды, assets, language keys, runtime-логику или пользовательское поведение.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Основная requirement канонического имени уже находится в `core-boundaries`; change объявляет `skip_specs: true`, поскольку очищает только тестовый и архивный текст.

## Impact

Затрагиваются `tests/test_project_docs.py` и четыре Markdown-файла в `openspec/changes/archive/`. Совместимость сервера, сборка Pawn, release automation, основной README и main specs не меняются. Архивированные артефакты сознательно нормализуются по прямому требованию пользователя, поэтому перестают быть дословным снимком прежнего написания, но сохраняют смысл решений и проверок.

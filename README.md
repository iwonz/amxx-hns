# Hide And Seek: Ultimate

Ядро режима Hide and Seek для Counter-Strike 1.6 на AMX Mod X. Террористы выступают прячущимися, Counter-Terrorists — ищущими: первым даётся время разбежаться и спрятаться, вторые после отсчёта должны найти и убить их.

Плагин управляет основным циклом раунда, командами игроков, экипировкой, правилами Flashbang, уроном от падения, автоматическим лечением и сообщениями. Это не готовая серверная сборка: карты, баланс, движение, anti-frag, статистика и дополнительные игровые механики подключаются отдельными AMXX-плагинами.

## Как проходит раунд

1. Новый раунд считается игровым, только если есть хотя бы один игрок в T и один в CT.
2. После стандартного `Round_Start` запускается дополнительный HNS-отсчёт продолжительностью от 1 до 10 секунд.
3. Во время отсчёта CT заморожены и при включённой настройке видят затемнение экрана. T могут разбежаться и спрятаться.
4. После отсчёта CT размораживаются и начинается поиск.
5. Плагин ждёт стандартного завершения раунда Counter-Strike:
   - если хотя бы один T жив, побеждают прячущиеся;
   - если живых T нет, побеждают ищущие, после чего T и CT меняются ролями.
6. При смене ролей также обновляется сохранённая команда игроков, ушедших через `/afk` или `/spec`.

Плагин не запускает таймер карты и не завершает раунд по собственному условию. Настройте стандартные параметры раунда Counter-Strike и используйте подходящие HNS-карты.

## Возможности

- отсчёт перед стартом с индивидуальным отключением звука;
- заморозка, затемнение и antiflash для CT во время отсчёта;
- возрождение погибших во время подготовительной фазы;
- автоматический вход в команду и ограничения ручной смены команды;
- переход в наблюдатели и возврат командами чата;
- выдача ножа и настраиваемого набора гранат после каждого spawn;
- запрет атаки ножом и скрытие модели ножа у T;
- правила ослепления владельца и союзников Flashbang;
- настраиваемый шанс отказа Flashbang и способ уведомления владельца;
- индикация урона от падения, звук, ScreenFade и отложенное лечение;
- удаление стандартных objective-сущностей, оружия карты, дверей и разрушаемых объектов;
- настраиваемые звуки победы;
- локализация всех сообщений на русский и английский через `hns.txt`.

## Требования

- сервер Counter-Strike 1.6;
- AMX Mod X 1.10 — на этой версии проект компилируется и проверяется;
- стандартные модули AMX Mod X: `cstrike`, `fakemeta`, `fun`, `hamsandwich`;
- компилятор `amxxpc` и include-файлы из пакета AMX Mod X для самостоятельной сборки.

Специальные зависимости ReHLDS, ReGameDLL или ReAPI не используются.

## Установка

### 1. Получите файлы плагина

Рекомендуемый вариант — открыть [GitHub Releases](https://github.com/iwonz/amxx-hns-ultimate/releases) и скачать из нужного стабильного выпуска три assets:

- `hns-v<version>.zip` — готовая структура сервера;
- `hns.amxx` — отдельный скомпилированный плагин;
- `SHA256SUMS` — контрольные суммы обоих файлов.

Положите три файла в один каталог и проверьте их до установки:

```sh
sha256sum -c SHA256SUMS
```

На macOS используйте `shasum -a 256 -c SHA256SUMS`. Обе строки должны завершиться статусом `OK`. После этого распакуйте `hns-v<version>.zip` непосредственно в `<server>/cstrike`: архив уже содержит `addons/amxmodx/...` и `sound/hns/...`.

Если готовый Release использовать нельзя, соберите плагин из исходников. Откройте каталог `addons/amxmodx/scripting` из официального пакета AMX Mod X 1.10 и выполните:

```sh
./amxxpc <repo>/src/scripting/hns.sma -iinclude -o<repo>/hns.amxx
```

На Windows используйте `amxxpc.exe`:

```bat
amxxpc.exe <repo>\src\scripting\hns.sma -iinclude -o<repo>\hns.amxx
```

Замените `<repo>` абсолютным путём к клону репозитория. Успешная сборка создаст `hns.amxx` без предупреждений AMX Mod X 1.10.

Не отделяйте `src/scripting/hns.sma` от каталога `src/scripting/hns/`: основной файл подключает оттуда внутренние `.inc`. Компилировать нужно только `hns.sma`; отдельные `.inc` не являются самостоятельными плагинами и не копируются на игровой сервер.

### 2. Разместите файлы на сервере

При установке готового ZIP эти пути уже созданы. Для ручной сборки скопируйте файлы самостоятельно; пути назначения указаны относительно `<server>/cstrike`.

| Из репозитория | На сервере |
| --- | --- |
| `hns.amxx` | `addons/amxmodx/plugins/hns.amxx` |
| `src/configs/hns.cfg` | `addons/amxmodx/configs/hns.cfg` |
| `src/data/lang/hns.txt` | `addons/amxmodx/data/lang/hns.txt` |
| каталог `src/sound/hns` | каталог `sound/hns` |

Не меняйте вложенность звуков: плагин ожидает файлы `sound/hns/countdown/1.wav` … `10.wav` и `sound/hns/falldown/1.wav`.

### 3. Подключите плагин и модули

Добавьте в `addons/amxmodx/configs/plugins.ini` строку:

```ini
hns.amxx
```

Проверьте, что необходимые модули не закомментированы в `addons/amxmodx/configs/modules.ini`:

```ini
fakemeta
hamsandwich
fun
cstrike
```

### 4. Перезапустите сервер или смените карту

После загрузки карты проверьте в серверной консоли:

```text
amxx plugins
amxx modules
```

У `hns.amxx` должен быть статус `running`, а четыре требуемых модуля должны быть загружены. Изменение звуков победы и настроек удаления сущностей требует смены карты.

## Команды игроков

| Команда | Назначение |
| --- | --- |
| `/cd` | Включить или выключить звук отсчёта только для себя. |
| `/afk`, `/spec` | Умереть без сообщения в kill feed, перейти в наблюдатели и запомнить текущую роль. |
| `/play`, `/back` | Вернуться из наблюдателей в сохранённую команду. |

Команды AFK работают только при `hns_afk_control "1"`. Обычное меню выбора команды регулируется отдельными настройками autojoin и смены команды.

## Конфигурация

Основной файл — `addons/amxmodx/configs/hns.cfg`. Плагин автоматически выполняет его после загрузки. Режимы команд во всех настройках имеют одинаковые значения: `0` — никто, `1` — только T, `2` — только CT, `3` — обе команды.

Числовые Cvar зарегистрированы через AMX Mod X 1.10 с допустимыми границами: сервер автоматически приводит выходящие за документированный диапазон значения к ближайшей границе. Изменения настроек применяются к runtime-логике без перезагрузки плагина, кроме путей к звукам победы, которые требуют нового precache после смены карты.

В таблицах приведены значения из поставляемого `hns.cfg`. Если файл отсутствует, некоторые встроенные значения отличаются.

### Раунд и отсчёт

| Cvar | По умолчанию | Назначение |
| --- | ---: | --- |
| `hns_timer` | `10` | Длительность HNS-отсчёта; код ограничивает значение диапазоном 1–10 секунд. |
| `hns_timer_immortal` | `1` | Возрождать погибших во время отсчёта. |
| `hns_timer_immortal_delay` | `3.0` | Задержка возрождения в секундах. |
| `hns_timer_antiflash_ct` | `1` | Блокировать эффект Flashbang на CT во время отсчёта. |
| `hns_cd_sound` | `1` | Глобально включить звуки отсчёта. |
| `hns_ct_timer_fade_screen` | `1` | Затемнять экран CT во время отсчёта. |
| `hns_ct_timer_fade_screen_r` | `0` | Красный канал затемнения, 0–255. |
| `hns_ct_timer_fade_screen_g` | `0` | Зелёный канал затемнения, 0–255. |
| `hns_ct_timer_fade_screen_b` | `0` | Синий канал затемнения, 0–255. |
| `hns_ct_timer_fade_screen_alpha` | `150` | Плотность затемнения, 0–255. |

### Победа и звуки

| Cvar | По умолчанию | Назначение |
| --- | ---: | --- |
| `hns_win_sound_mode` | `3` | `0` — выкл., `1` — победа T, `2` — победа CT, `3` — обе команды. |
| `hns_win_sound_hiders` | `radio/terwin.wav` | Звук победы прячущихся относительно каталога `sound`. |
| `hns_win_sound_seekers` | `radio/ctwin.wav` | Звук победы ищущих относительно каталога `sound`. |

Пользовательский WAV-файл необходимо заранее положить в `cstrike/sound`. Путь ограничен 63 символами и применяется после смены карты, потому что звуки загружаются в `plugin_precache`.

### Экипировка и Flashbang

| Cvar | По умолчанию | Назначение |
| --- | ---: | --- |
| `hns_hegrenade_mode` | `0` | Кому выдавать HE Grenade. |
| `hns_flashbang_mode` | `1` | Кому выдавать Flashbang. |
| `hns_flashbang_count` | `2` | Количество Flashbang; фактический максимум — 2. |
| `hns_smokegrenade_mode` | `1` | Кому выдавать Smoke Grenade. |
| `hns_flash_flasher` | `0` | Может ли Flashbang ослеплять бросившего игрока. |
| `hns_flash_teammate` | `0` | Может ли Flashbang ослеплять союзников. |
| `hns_flashbang_failure_chance` | `90` | Шанс отказа Flashbang, 0–100. Встроенное значение при отсутствии конфига — `0`. |
| `hns_flashbang_failure_notify` | `1` | Уведомление об отказе: `0` — нет, `1` — чат, `2` — DHUD, `3` — звук. |
| `hns_tr_fake_knife_mode` | `2` | Нож T: `0` — обычный, `1` — без атак, `2` — без атак и без модели. |

После каждого spawn плагин удаляет всё оружие игрока, выдаёт нож и затем гранаты согласно этим настройкам.

### Урон от падения и лечение

| Cvar | По умолчанию | Назначение |
| --- | ---: | --- |
| `hns_falldown_show_dmg` | `1` | Показывать величину урона от падения. |
| `hns_falldown_play_sound` | `1` | Проигрывать `hns/falldown/1.wav`. |
| `hns_falldown_fadescreen` | `1` | Показывать ScreenFade после падения. |
| `hns_falldown_fadescreen_r` | `255` | Красный канал ScreenFade, 0–255. |
| `hns_falldown_fadescreen_g` | `0` | Зелёный канал ScreenFade, 0–255. |
| `hns_falldown_fadescreen_b` | `0` | Синий канал ScreenFade, 0–255. |
| `hns_falldown_fadescreen_alpha` | `80` | Плотность ScreenFade, 0–255. |
| `hns_autoheal` | `1` | Включить отложенное восстановление урона от падения. |
| `hns_autoheal_mode` | `3` | Для каких команд работает лечение. |
| `hns_autoheal_max_hp` | `65` | Максимальное количество HP, возвращаемое за одно падение; это не предел итогового HP. |
| `hns_autoheal_delay` | `1.5` | Задержка лечения в секундах. |

Новое падение до выполнения предыдущего лечения заменяет запланированное лечение последним полученным уроном.

Эффекты падения и лечение запускаются только после реально применённой положительной потери HP, если игрок пережил урон. Сам плагин не подменяет стандартный `Ham_TakeDamage`, поэтому сохраняется совместимость с другими damage-hooks.

### Команды и доступ

| Cvar | По умолчанию | Назначение |
| --- | ---: | --- |
| `hns_autojoin` | `1` | Автоматически выбирать команду при подключении. |
| `hns_autojoin_immunity` | `1` | Разрешать игрокам с флагом самим выбрать начальную команду. |
| `hns_autojoin_immunity_flag` | `t` | Флаг иммунитета autojoin. |
| `hns_change_team` | `0` | Разрешать обычную смену команды во время игры. |
| `hns_change_team_immunity` | `1` | Разрешать смену команды игрокам с флагом. |
| `hns_change_team_immunity_flag` | `t` | Флаг иммунитета ограничения смены команды. |
| `hns_afk_control` | `1` | Включить `/afk`, `/spec`, `/play`, `/back`. |
| `hns_afk_timer_revive` | `1` | Возрождать вернувшегося игрока, если ещё идёт отсчёт. |

AMX Mod X-флаги задаются буквами; `t` — пользовательский флаг `ADMIN_LEVEL_H`.

### Сущности карты

| Cvar | Встроенное значение | Назначение |
| --- | ---: | --- |
| `hns_remove_doors` | `1` | Удалять `func_door` и `func_door_rotating`. |
| `hns_remove_breakables` | `1` | Удалять `func_breakable`. |

Независимо от этих Cvar плагин удаляет bomb/hostage/escape/VIP-зоны, hostage/scientist, `armoury_entity` и связанные objective-сущности.

## Локализация

Все видимые игрокам тексты находятся в `src/data/lang/hns.txt`. Русский `[ru]` и английский `[en]` разделы должны содержать одинаковый набор ключей и совместимые параметры форматирования.

При добавлении сообщения:

1. добавьте ключ сразу в `[ru]` и `[en]`;
2. используйте в Pawn `%L`, `ChatColorKey` или другую AMXX dictionary-функцию;
3. не добавляйте русские или английские пользовательские строки непосредственно в Pawn-исходники `src/scripting/`.

## Известные ограничения

- Режим рассчитан на стандартный лимит Counter-Strike — до 32 игроков.
- Плагин реагирует на стандартный `Round_End`, но сам не определяет момент окончания раунда.
- Нет anti-frag, системы очков/рангов, админ-меню, выбора карт, баланса команд, blockmaker, bhop/stamina или сохранения данных.
- Нет публичных AMXX natives/forwards: расширение возможно отдельными плагинами через стандартные события и Cvar, но формального API ядро не предоставляет.
- Контекст Flashbang хранится для последней обрабатываемой детонации; отдельной очереди одновременно взорвавшихся гранат нет.
- `hns_remove_doors` и `hns_remove_breakables` зарегистрированы кодом, но отсутствуют в поставляемом `hns.cfg`; они читаются при spawn сущностей, поэтому изменение проявляется только на следующей загрузке карты.
- `src/sound/hns/start/1.wav` сейчас не вызывается кодом и не требуется для работы.

## Разработка

Структура проекта:

```text
src/scripting/hns.sma       composition root и единственная точка компиляции
src/scripting/hns/          внутренние модули, собираемые в тот же hns.amxx
src/configs/hns.cfg         поставляемая конфигурация, кодировка CP1251
src/data/lang/hns.txt       словарь RU/EN, UTF-8
src/sound/hns/              игровые WAV-файлы
tests/                      регрессионные проверки исходника и документации
```

`hns.sma` хранит metadata плагина, регистрацию Cvar/hooks, client lifecycle, общий `FM_Think`, precache orchestration и кросс-функциональную очистку задач. Внутренние модули разделены по ответственности:

| Модуль | Ответственность |
| --- | --- |
| `definitions.inc` | Общие лимиты, диапазоны task ID и bound runtime-состояние Cvar. |
| `player_state.inc` | Состояние, индексируемое по player id. |
| `ui.inc` | ChatColor, DHUD и ScreenFade helpers. |
| `map_rules.inc` | Удаление сущностей карты и отключение buyzone. |
| `fall_damage.inc` | Урон от падения, feedback и autoheal. |
| `equipment.inc` | Выдача оружия и fake knife hooks. |
| `team_flow.inc` | AFK, autojoin, смена команд и swap ролей. |
| `round.inc` | Завершение раунда, сообщения и звуки победы. |
| `countdown.inc` | Подготовительный отсчёт, freeze и revive. |
| `flashbang.inc` | Отслеживание Flashbang, отказ гранаты и правила ослепления. |

Все `.inc` имеют общее пространство имён Pawn и являются внутренними частями одного плагина. Публичных natives/forwards или стабильного include API для сторонних плагинов эта структура не добавляет.

Запуск тестов:

```sh
python3 -B -m unittest discover -s tests -v
```

Проверка пробелов и конфликтных маркеров:

```sh
git diff --check
```

Для проверки сборки скомпилируйте только `hns.sma` официальным компилятором AMX Mod X 1.10; каталог `src/scripting/hns/` должен оставаться рядом с ним. Отдельный `dhudmessage.inc` не нужен: DHUD natives входят в официальный `amxmodx.inc`.
